Fetch your data

The kit provides apiFetch — an authenticated fetch wrapper that attaches the bearer token and handles errors. Here is how to use it.

1. Create the demo collection

In your RESTHeart Cloud dashboard, create a collection called demo and add a permission so the signed-in user can read it: 

path(/demo) and method(GET)

2. Fetch from your component

import { Component, inject, signal } from '@angular/core';
import { switchMap, map } from 'rxjs';
import { RhAuthService } from '@restheart-cloud/kit-ng';

@Component({ /* ... */ })
export class DemoComponent {
  private auth = inject(RhAuthService);
  items = signal<unknown[]>([]);

  ngOnInit() {
    this.auth.api('/demo').pipe(
      switchMap(res => res.json()),
      map(json => Array.isArray(json) ? json : []),
    ).subscribe(data => this.items.set(data));
  }
}

3. Try it now

Press the button to fetch /demo from your service.
